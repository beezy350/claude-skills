# claude-skills

My default Claude Code skills, usable in every project.

| Skill | Use it for | Source |
|---|---|---|
| find-skills | Finding the right skill for a task | vercel-labs/skills |
| playwright-cli | Studying websites, screenshots, browser testing | microsoft/playwright-cli |
| ui-ux-pro-max | UI/UX design, palettes, font pairings | nextlevelbuilder/ui-ux-pro-max-skill |
| taste-skill | Premium, non-generic frontend design | Leonxlnx/taste-skill |
| copywriting, copy-editing, product-marketing | Landing pages and content copy | coreyhaines31/marketingskills |
| pdf, docx, pptx | PDFs, Word guides, slide decks and carousels | anthropics/skills |
| canvas-design | Covers, posters and visuals | anthropics/skills |
| skill-creator | Building new skills | anthropics/skills |

Each skill keeps its original license file where one was provided.

## Install

On your computer:

```bash
git clone https://github.com/beezy350/claude-skills && ./claude-skills/install.sh
```

In a Claude Code cloud environment, add this line to the environment's setup script:

```bash
git clone --depth 1 https://github.com/beezy350/claude-skills /tmp/claude-skills && /tmp/claude-skills/install.sh
```
